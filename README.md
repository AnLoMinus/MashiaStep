# 🕎 עקבתא דמשיחא - מאגר תוכן מרכזי

אתר אינטרנט מרכזי המאגד את כל התוכן הקשור לנושא "עקבתא דמשיחא" (סימני עקבות המשיח) ממגוון מסמכים ומקורות.

## 📖 אודות הפרויקט

פרויקט זה נוצר כדי לרכז ולאגד את כל החומר התורני והמחשבתי הקשור לתקופת עקבתא דמשיחא, כולל:

- תוכן עניינים מפורט של הספר
- מאגר תוכן מרכזי
- לקט משפטי השראה ומשני תודעה
- צידה לדרך - כללי התנהגות
- מבנה הפרקים של הספר
- תוכן מפורט על מאפייני התקופה

## 🚀 התחלה מהירה

1. שכפל את הפרויקט:

```bash
git clone https://github.com/AnLoMinus/MashiaStep.git
cd MashiaStep
```

2. פתח את הקובץ `index.html` בדפדפן

3. זה הכל! האתר הוא סטטי ואינו דורש שרת או התקנות נוספות.

## 📁 מבנה הפרויקט

```
MashiaStep/
├── index.html          # עמוד הבית הראשי
├── styles.css          # קובץ עיצוב CSS
├── README.md           # קובץ זה
├── ROADMAP.md          # תכנית פיתוח עתידית
├── TODO.md             # רשימת משימות

```

## ✨ תכונות

- 🎨 **עיצוב מודרני ויפה** - עיצוב נעים עם גרדיאנטים וצבעים יפים
- 📱 **רספונסיבי** - עובד מצוין על מובייל, טאבלט ומחשב
- 🔍 **ניווט קל** - ניווט חלק בין הסעיפים השונים
- 📊 **טבלאות מסודרות** - הצגה ברורה של המידע
- 🎯 **הדגשות צבעוניות** - סימון ברור של מה מותר ומה אסור
- 🌐 **תמיכה מלאה בעברית** - RTL וריפוד מותאם
